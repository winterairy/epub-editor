# EPUB Reader

Windows용 EPUB 전자책 리더 애플리케이션입니다.

## 프로젝트 개요

TypeScript, React, Electron을 사용하여 개발되는 데스크톱 EPUB 리더 애플리케이션입니다.

## 기술 스택

- **언어**: TypeScript
- **UI 프레임워크**: React
- **데스크톱 프레임워크**: Electron
- **EPUB 처리**: epub.js

### 기술 스택 선택 이유

#### React (Next.js 대신)

- **Next.js는 SSR/SSG에 특화**: Next.js는 서버 사이드 렌더링과 정적 사이트 생성에 최적화되어 있으나, Electron 데스크톱 앱에서는 서버가 없으므로 이러한 기능이 불필요합니다.
- **React가 더 가볍고 유연함**: Electron 환경에서는 클라이언트 사이드 렌더링만 필요하므로, React만으로 충분하며 번들 크기도 더 작습니다.
- **Electron과의 통합**: React는 Electron과의 통합이 더 단순하고, 많은 Electron 앱들이 React를 사용하고 있어 커뮤니티 지원이 풍부합니다.
- **라우팅 제어**: Electron 앱은 단일 페이지 애플리케이션으로 동작하므로, Next.js의 자동 라우팅 기능이 오히려 복잡성을 증가시킬 수 있습니다.

#### Electron

- Windows, macOS, Linux 크로스 플랫폼 지원
- 웹 기술(HTML, CSS, JavaScript/TypeScript) 활용 가능
- 파일 시스템 접근 및 네이티브 기능 사용 가능
- 널리 사용되어 검증된 기술 스택

#### TypeScript

- 타입 안정성 제공
- React와 Electron 모두 TypeScript를 공식 지원
- 대규모 프로젝트 유지보수에 유리

#### epub.js

- 브라우저/Electron 환경에서 EPUB 파일 파싱 및 렌더링
- TypeScript 타입 정의 제공
- 활발한 커뮤니티 지원

## 파일 저장 전략

### EPUB 파일 저장

**선택한 방식: 원본 파일 유지 (파일 복사 없음)**

- 사용자가 EPUB 파일을 직접 선택하여 읽는 방식
- EPUB 파일은 원본 위치에 그대로 유지 (애플리케이션이 복사하지 않음)
- Electron의 `dialog.showOpenDialog()` API를 사용하여 파일 선택
- 파일 경로를 애플리케이션 메타데이터에 저장하여 나중에 다시 열 수 있도록 함

**장점:**

- 디스크 공간 절약 (파일 중복 없음)
- 사용자가 파일을 직접 관리할 수 있음
- 외부에서 EPUB 파일을 수정해도 즉시 반영 가능

**단점:**

- 파일이 이동되거나 삭제되면 접근 불가
- 네트워크 드라이브나 외부 저장소의 경우 성능 이슈 가능

### 메타데이터 저장

**저장 위치: Electron userData 디렉토리**

```
Windows: C:\Users\<사용자>\AppData\Roaming\epub-reader\
```

**저장 방식: JSON 파일 기반**

**구조:**

```
userData/
├── library.json              # 라이브러리 메타데이터
├── books/
│   ├── <book-id-1>.json      # 책별 상세 메타데이터
│   ├── <book-id-2>.json
│   └── ...
└── settings.json             # 애플리케이션 설정
```

**책 식별 방법:**

1. **파일 경로 해시 (권장)**

   - 파일 경로를 SHA-256 해시하여 고유 ID 생성
   - 파일 경로가 변경되면 ID도 변경됨 (의도된 동작)
   - 예: `sha256("C:\Users\...\book.epub")` → `a3f5b2c1...`

2. **파일 경로 + 수정 시간**
   - 파일 경로와 수정 시간을 조합하여 ID 생성
   - 파일이 업데이트되면 새 책으로 인식

**library.json 구조:**

```json
{
  "version": "1.0",
  "books": [
    {
      "id": "a3f5b2c1...",
      "filePath": "C:\\Users\\...\\book.epub",
      "title": "책 제목",
      "author": "저자명",
      "coverImage": "data:image/jpeg;base64,...",
      "addedAt": "2024-01-15T10:30:00Z",
      "lastReadAt": "2024-01-20T14:20:00Z",
      "status": "reading",
      "progress": 0.35,
      "currentPage": 42,
      "totalPages": 120
    }
  ]
}
```

**books/<book-id>.json 구조 (책별 상세 데이터):**

```json
{
  "id": "a3f5b2c1...",
  "filePath": "C:\\Users\\...\\book.epub",
  "bookmarks": [
    {
      "id": "bm-001",
      "cfi": "epubcfi(/6/4[chap01ref]!/4/2/2[para1]/3:10)",
      "text": "북마크 위치의 텍스트 미리보기",
      "note": "중요한 부분",
      "createdAt": "2024-01-16T09:15:00Z",
      "page": 15
    }
  ],
  "highlights": [
    {
      "id": "hl-001",
      "cfi": "epubcfi(/6/4[chap01ref]!/4/2/2[para1]/3:10)",
      "text": "하이라이트된 텍스트",
      "color": "#FFEB3B",
      "note": "메모 내용",
      "createdAt": "2024-01-16T10:20:00Z"
    }
  ],
  "readingHistory": [
    {
      "date": "2024-01-20",
      "pagesRead": 5,
      "timeSpent": 1800
    }
  ],
  "annotations": [
    {
      "id": "ann-001",
      "cfi": "epubcfi(/6/4[chap01ref]!/4/2/2[para1]/3:10)",

```

**대안: SQLite 데이터베이스**

- 더 복잡한 쿼리가 필요한 경우
- 대량의 데이터 처리에 유리
- 하지만 JSON 파일이 더 단순하고 충분함

**데이터 동기화 전략:**

1. **파일 열기 시:**

   - 파일 경로 해시로 ID 생성
   - `books/<id>.json` 파일이 존재하는지 확인
   - 없으면 새로 생성, 있으면 기존 데이터 로드

2. **북마크/하이라이트 추가 시:**

   - 즉시 해당 책의 JSON 파일에 저장
   - 메모리 캐시도 업데이트

3. **진행 상태 저장:**

   - 페이지 이동 시 주기적으로 저장 (예: 5초마다 또는 페이지 변경 시)
   - `library.json`의 해당 책 항목 업데이트

4. **파일 경로 변경 감지:**
   - 파일 열기 시 파일 존재 여부 확인
   - 파일이 없으면 사용자에게 경로 재선택 요청
   - 또는 라이브러리에서 제거

**데이터 백업 및 복원:**

- **백업**: 사용자가 설정에서 백업 파일 생성 가능. `userData` 디렉토리 전체를 ZIP으로 압축하거나 JSON 파일들을 선택적으로 백업
- **복원**: 백업 파일에서 메타데이터 복원. EPUB 파일 경로가 변경된 경우 경로 매핑 기능 제공

**성능 고려사항:**

- **대용량 라이브러리**: `library.json`이 너무 커지면 (1000권 이상) 페이지네이션 또는 인덱싱 고려. 또는 SQLite로 전환 검토
- **파일 I/O 최적화**: 메모리 캐시 활용, 배치 쓰기 (여러 변경사항을 모아서 한 번에 저장), 비동기 파일 작업

## UI 구조

### 창 구조: 단일 창 + 탭 형식

**선택한 방식: 브라우저 스타일 탭 인터페이스**

- **단일 메인 윈도우**: 애플리케이션은 하나의 메인 윈도우로 실행됩니다.
- **탭 기반 읽기**: EPUB 파일을 열면 새 탭이 생성되어 여러 책을 동시에 열어둘 수 있습니다.
- **라이브러리 탭**: 항상 첫 번째 탭은 "라이브러리" 탭으로 고정되어 있습니다.

**장점:**

- 여러 책을 동시에 읽을 수 있어 편리함
- 메모리 효율적 (새 창을 열지 않음)
- 브라우저와 유사한 친숙한 UX
- 탭 간 전환이 빠르고 직관적

**대안 (단일 뷰 방식):**

- EPUB 파일을 열면 라이브러리 뷰가 읽기 뷰로 전환
- "뒤로 가기" 버튼으로 라이브러리로 복귀
- 더 단순하지만 여러 책 동시 읽기 불가

## 주요 기능

- EPUB 파일 열기 및 읽기
- 라이브러리 관리
- 목차 네비게이션
- 읽기 진행 상태 저장
- 북마크 및 하이라이트
- 커스터마이징 가능한 읽기 환경
